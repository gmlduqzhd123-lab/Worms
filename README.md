# 조준! 각도왕

각도와 바람을 읽고 조준하는 브라우저 턴제 전략 게임입니다. HTML·CSS·JavaScript와 Canvas로 구성되며, 게임 실행에 외부 서버·API 키·패키지 설치가 필요하지 않습니다.

[게임 실행](https://gmlduqzhd123-lab.github.io/Worms/) · [오프라인 단일 HTML](https://gmlduqzhd123-lab.github.io/Worms/offline/wormfront.html) · [배포 안내](DEPLOYMENT.md) · [변경 이력](CHANGELOG.md)

## 현재 버전

게임 버전은 **v28**, 서비스 워커 캐시는 `worms-v28`입니다. v28에서는 보통 CPU의 난이도를 완화하고, 안전한 위치에 양 팀을 섞어 배치하며, 포탄·피격·사망 효과와 전체 예상 탄도를 개선했습니다. 무기 피해량과 기존 물리 판정 계수는 유지했습니다.

현재 단일 HTML은 `dist/wormfront-stage28-offline.html`입니다. [v28 검수 보고서](verification/battle-improvements-2026-10-27/REPORT.md)에서 변경 범위와 당시 검증 결과를 확인할 수 있습니다. 이전 단계의 안내는 [변경 이력](CHANGELOG.md)에 보존했습니다.

## 주요 기능

- CPU 대전과 같은 기기에서 번갈아 플레이하는 로컬 2인 대전. CPU 난이도 3단계, 팀당 각도봇 2~6명, 각도봇 외형 10종을 지원합니다.
- 맵 테마 10종, 무작위 지형, 지형 파괴, 바람·중력·낙하 피해·감응타일·아이템 상자·수위 상승을 적용합니다. 모든 테마의 중력과 물 접촉 규칙은 같습니다.
- 포격·분열탄·설치형 폭탄·근접 공격·자석와이어·쌍날개팩·좌표비콘·연결발판 등 무기와 도구 19종을 제공합니다.
- 0°·30°·45°·60°·90° 선택과 ±1° 조준, 충전량에 따른 예상 탄도, 전체 경로 보기, 카메라 드래그·확대·봇 추적을 지원합니다.
- 모바일 가로 화면의 터치 조작, 세로 회전 시 자동 일시정지, 전체 위치 보기·봇 소개·소개 건너뛰기, 게임 종료 확인을 제공합니다.
- 플레이 가이드, 배경음악·효과음의 개별 음량, 앱 설치 안내, 오프라인 캐시, 설정·최근 완료 대전 30개 저장과 JSON 내보내기를 지원합니다.

## 실행

공개 주소를 열고 게임 모드와 맵을 고른 뒤 **전투 시작**을 누릅니다. 팀 이름·외형·난이도·봇 수·전투 규칙·음량은 시작 화면의 **추가 설정**에서 변경합니다.

로컬에서는 Node.js로 미리보기를 실행할 수 있습니다.

```sh
node scripts/serve.cjs
```

주소는 <http://127.0.0.1:4187>입니다. 폴더 구조를 유지해야 이미지와 음악을 함께 읽을 수 있습니다. `index.html`을 직접 여는 방식은 브라우저의 `file://` 정책에 따라 MP3 로딩이 제한될 수 있습니다.

인터넷 없이 파일 하나로 실행하려면 `dist/wormfront-stage28-offline.html`을 엽니다. 공개 웹앱은 첫 방문에서 리소스 캐시를 마친 뒤 오프라인으로 다시 열 수 있습니다. 앱 설치 지원 여부와 전체 화면 동작은 브라우저에 따라 다릅니다.

## 조작

| 동작 | 키보드·마우스 |
| --- | --- |
| 이동·점프 | A/D 또는 ←/→ 이동, W 점프, 0.33초 안에 W를 다시 눌러 백플립 |
| 조준·발사 | ↑/↓ 조준, Shift+↑/↓ 또는 ±1° 버튼으로 미세 조준, Space를 누르고 충전한 뒤 놓아 발사 |
| 무기 선택 | 아래 무기 목록 또는 숫자 1~9 |
| 목표 선택 | 좌표비콘·별똥지원·추적광구 등은 목표 지점을 클릭 |
| 카메라 | 화면 드래그, 휠·+/− 확대, M 전체 맵, C 봇 추적, Z/X 좌우 이동 |
| 자석와이어 | A/D 스윙, W/S 길이 조절, Space 해제 |
| 쌍날개팩 | A/D 이동, W/S 상승·하강 |
| 차례·일시정지 | Enter 턴 넘김, Escape 일시정지·재개 |

모바일에서는 화면의 이동·점프·조준·발사 버튼을 사용합니다. 발사는 누른 채 충전하고 손을 떼면 나갑니다. 두 손가락으로 확대·축소하며, 보조 버튼으로 상승·하강·와이어 길이·턴 넘김을 조작합니다.

## 저장과 예측의 범위

설정·가이드 완료·대전 결과는 현재 브라우저의 `localStorage`에만 저장합니다. 저장 키는 `wormfront.settings.v1`, `wormfront.guide.v1`, `wormfront.results.v1`입니다. 기기 간 동기화와 온라인 대전은 없으며, 진행 중인 대전의 이어하기는 지원하지 않습니다. 브라우저 저장이 차단되면 현재 화면에서만 유지됩니다. HTTP 주소와 `file://` 파일의 저장 공간은 다를 수 있습니다.

예상 탄도는 실제 발사와 같은 고정 시간 계산을 사용합니다. 분열탄은 모탄이 끝나는 위치까지 예측하며 후속 조각은 포함하지 않습니다. 이후 움직이는 캐릭터와 파괴되는 지형에 따라 결과가 달라질 수 있습니다. 추적광구는 목표 선택 후 경로를 표시합니다.

CPU는 안전한 보행과 사격 후보를 계산합니다. 쉬움·보통은 바람포·통통캡슐을, 어려움은 추적광구도 사용하며 가까운 적에게는 반동해머를 사용할 수 있습니다. CPU의 와이어·쌍날개팩·점프 경로 탐색과 모든 무기의 전술 사용은 아직 포함하지 않습니다.

## 빌드와 검증

개발·자동 검증에는 **Node.js 24**를 권장합니다. 게임 실행용 라이브러리는 추가하지 않으며, `package.json`과 lockfile은 검증 도구의 버전을 고정합니다.

```sh
npm ci
npx playwright install chromium
npm run check
npm run build
npm test
```

Linux에서는 브라우저 시스템 의존성까지 설치하도록 `npx playwright install --with-deps chromium`을 사용합니다. `npm start`는 로컬 미리보기 서버를 실행합니다.

| 명령 | 검사·출력 범위 |
| --- | --- |
| `npm run check` | 브라우저 없이 스크립트 순서·문법·버전·필수 파일 확인 |
| `npm run build` | 현재 HTML 버전으로 오프라인 HTML을 만든 뒤 배포 폴더와 해시 명세 생성 |
| `npm test` | 구조 검사, 기존 전투·효과음 회귀, 생성된 배포본의 브라우저 기본 동작 검사 |

`npm test` 전에 `npm run build`를 실행합니다. 출력은 `dist/wormfront-stage28-offline.html`, `release/site/`, `release/manifest.json`이며, 검증 결과는 `test-results/`에 저장합니다. `release/site/offline/wormfront.html`은 현재 소스에서 생성된 단일 파일입니다. 기존 설치 브라우저로 검사하려면 `WORMFRONT_BROWSER_CHANNEL` 환경 변수를 `msedge` 또는 `chrome`으로 설정할 수 있으며, 기본값은 Playwright Chromium입니다.

자동 검증은 핵심 회귀와 배포본 검사를 실행합니다. 과거 보고서에 기록된 모든 플랫폼·실험 검사를 매번 실행하는 것은 아닙니다. 자세한 자동 검증·배포 절차는 [배포 안내](DEPLOYMENT.md)를 참고하세요.

## 자동 배포

`main`을 대상으로 한 PR에서도 검증과 빌드를 실행합니다. `main` 푸시 또는 기본 브랜치에서 수동 실행하면 의존성 설치 → 브라우저 설치 → 구조 검사 → 빌드 → 브라우저 검증을 거치며, 모두 통과해야 `release/site/`를 GitHub Pages에 배포합니다. 검증이 실패하면 배포를 중단합니다.

배포본의 단일 HTML은 워크플로에서 현재 소스로 다시 생성합니다. 따라서 소스를 수정할 때 저장소의 이전 생성 파일에 의존하지 않습니다. 검증 도구·검수 자료·이전 버전 보존본은 사이트에 포함하지 않습니다.
