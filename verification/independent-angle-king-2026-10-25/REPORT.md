# 각도 정확도·독자 디자인·권리 기록 보완 — 2026-10-25

## 적용 내용

1. 표시 각도와 초기 발사 방향: 수평 속도에만 배율이 있던 방식을 수정했습니다. 수평·수직 속도를 동일하게 확대하고 중력·바람 가속도도 같은 배율로 적용해 발사 방향을 보존했습니다. 이전 단일 배율 버전(stage18) 대비 수평 사정거리 약 2배와 도화선 시간을 유지합니다. 유도탄도 표적 방향 벡터를 동일 좌표계에서 계산합니다. CPU는 동일한 createBallistic/advanceBallistic 경로를 사용합니다. 높아진 수직 탄도를 카메라가 월드 상단 바깥에서도 추적합니다.
2. 정밀 조준: 90°까지 조준하며 0·30·45·60·90° 선택, ±1° 버튼, Shift+방향키를 지원합니다. 일반 플레이어 조준도 정수 각도로 맞춰 표시와 초기 방향이 어긋나지 않습니다. 모바일 정밀 조준부는 하단 중앙의 빈 공간에 배치했습니다. 수평선 기준·비행 중 중력과 바람의 영향을 가이드에 설명했습니다.
3. 캐릭터: 새 삼각형 섀시·단일 카메라 눈·기계 다리의 각도봇 10종을 제작했습니다. 기존 게임 이미지를 입력하지 않고 새 콘셉트로 imagegen에서 생성했습니다. 선택 목록 0~9는 유지해 이전 설정과 호환합니다.
4. 도구: 바람포·통통캡슐·별빛코어·자석와이어·태엽수레·시간큐브·감응타일·충격글러브·좌표비콘·쌍날개팩 10종을 새로 그렸고 나머지 도구 이름과 도형 아이콘도 맞췄습니다. 별빛코어는 유리질 전자음과 ‘별빛 방출!’ 연출, 태엽수레는 기어 시동음을 사용합니다. 기존 기능·탄약 저장 키는 유지합니다. 이미지 실패 시 사용하는 도형도 새 형태로 교체했습니다.
5. 연동 이미지: 시작 화면 캐릭터·앱 아이콘 5종·대표 이미지 og-image-angle-bots.png(1730×909)를 새 디자인으로 적용했습니다. 설치 아이콘 URL에 v=25를 넣어 이전 이미지와 구분하고 오프라인 파일에도 새 아이콘을 포함합니다. 접속 URL·manifest id·저장 키는 유지합니다.
6. 권리 기록: ASSET_RIGHTS.md, assets/rights-manifest.json, 제작 정보 창을 추가하고 생성 원본·전체 프롬프트·분리 경계·SHA-256을 기록했습니다. Suno 유료 제작·다운로드는 사용자의 확인에 근거하며 계정·영수증을 독립 검증한 것은 아닙니다. 배경 참고 자료 권리와 AI 결과물의 독점적 저작권·비침해는 확정하지 않았습니다. KIPRIS 국내 문자 상표 기초 조회에서 각도왕/조준각도왕 완전일치 결과가 없었으며 범위·한계는 TRADEMARK_REVIEW.md에 기록했습니다.
7. 기기 검수: 데스크톱·Android 크기·작은 모바일 크기의 실제 Edge 브라우저 검수를 진행했습니다. 실제 안드로이드 설치·카카오톡 공유는 사용자가 확인하기로 했으며 결과는 ANDROID_CHECKLIST.md에 별도로 기록합니다. 에뮬레이션을 실기기 PASS로 표시하지 않습니다.
