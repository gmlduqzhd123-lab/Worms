# 실제 안드로이드 확인 항목

현재 상태: 사용자 실기기 확인 완료(2026-10-25). 새 배포 주소의 화면·조준·설치·카카오톡 공유 확인 요청에 사용자가 ‘확인 완료!’라고 회신했습니다. 항목별 상세 결과나 기종·버전은 제공되지 않았으므로 아래는 사용자의 종합 확인 회신으로 기록하며, 개발자의 직접 기기 검사 및 브라우저 에뮬레이션 검사와 구분합니다.

주소: https://gmlduqzhd123-lab.github.io/Worms/?v=25

1. Android Chrome에서 열어 새 삼각형 각도봇이 표시되는지 확인합니다. 화면을 세로·가로로 바꿔 회전 안내와 게임 화면 맞춤을 확인합니다.
2. 전투를 시작하고 소개를 건너뛴 뒤 90°를 선택합니다. ±1° 버튼으로 89°·90°가 정확히 바뀌는지, 버튼과 눈금이 가리지 않는지 확인합니다. 발사 직후 방향은 수직이며 비행 중에는 바람의 영향을 받을 수 있습니다.
3. 앱 설치 메뉴에서 표시 이름이 ‘조준! 각도왕’, 아이콘이 새 삼각봇인지 확인합니다. 기존 설치 앱이 있다면 현재 상태에서 이름·아이콘을 확인합니다.
4. 카카오톡 ‘나와의 채팅’에 주소를 붙여 넣어 공유 제목이 ‘조준! 각도왕’, 대표 이미지가 새 각도봇 그림인지 확인합니다.

회신 형식: 기종 / Android 버전 / 브라우저 이름·버전 / 화면·90°·±1° 결과 / 설치 이름·아이콘 결과 / 카카오톡 카드 결과.
