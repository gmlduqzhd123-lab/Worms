# 명칭 기초 조회 — 2026-10-25

공식 KIPRIS(https://www.kipris.or.kr/khome/main.do)의 상표 탭에서 직접 조회했습니다. 검색 화면의 기본 행정상태(출원·공고·등록)를 기준으로 한 국내 문자 명칭의 기초 조회입니다.

| 검색 | 방식 | 관찰 결과 |
| --- | --- | --- |
| 각도왕 | 일반 검색 후 상표 탭 | 검색결과 없음 |
| TNM=[각도왕] | 상세검색의 상표명칭 ‘완전일치’ 선택으로 만든 검색식 | 검색결과 없음 |
| TNM=[조준각도왕] | 같은 완전일치 검색식에 공백·문장부호를 제외한 전체 명칭 입력 | 검색결과 없음 |

증거: trademark-angle-king.png, trademark-full-name.png, trademark-final-ax.txt. 느낌표를 일반 검색에 직접 넣으면 검색 연산자로 처리될 수 있어 해당 일반 검색 결과는 동일 명칭 조회 결과로 사용하지 않았습니다.

이 결과는 ‘동일 문자열이 확인되지 않았다’는 범위의 기초 조사입니다. 유사한 발음·관념·도형, 영어·외국어 표기, 지정 상품·서비스 분류별 유사성, 해외 권리, 미공개 출원, 데이터 갱신 시차 및 등록 가능성을 모두 판단한 결과가 아닙니다. ‘상표 문제가 없다’거나 ‘등록 가능’하다는 확정 결론으로 사용하지 않습니다. 출원·사업화 단계에서는 변리사 등 전문가의 지정상품별 선행상표 검토가 별도로 필요합니다.
