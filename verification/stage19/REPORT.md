# 19단계 사정거리 확대와 간편한 시작 화면

## 변경 사항

로켓·수류탄·바나나탄·성스러운 폭탄·클러스터·박격포·유도탄의 수평 추진력을 2배로 조정하고 산탄총의 사거리를 2배로 늘렸습니다. 충전량에 따른 거리 차이, 수직 속도·중력·도화선 시간과 무기별 튕김 규칙은 유지합니다. 수평 바람과 유도탄 추적 계산도 같은 비율로 반영합니다. 공습과 자탄의 별도 운동 규칙은 기존 값을 유지합니다.

CPU는 실제 탄환과 같은 createBallistic/advanceBallistic 함수를 사용합니다. 이 공통 계산에 거리 확대를 적용하여 조준 예측과 실제 발사가 동일한 경로를 따릅니다.

시작 화면에는 게임 모드, 팀 이름, 팀별 캐릭터와 맵 테마 선택을 남겼습니다. CPU 난이도, 팀 인원, 턴 시간, 맵 크기, 상자 빈도, 서든데스, 초기 지뢰, 배경음악·효과음 음량은 접고 펼칠 수 있는 ‘추가 설정’에 모았습니다. 새로 열 때 추가 설정은 닫혀 있고, 기존 기본값과 저장된 값은 그대로 적용합니다. 게임 시작 버튼은 작은 화면에서도 바로 보이도록 하단에 유지합니다. 작은 화면에서는 설정 영역을 스크롤할 수 있습니다.

## 거리·CPU·화면 검수

이전 18단계와 변경본을 실제 Edge 브라우저에서 비교했습니다. 무풍·고정 각도·빈 공간의 통제된 조건에서 7종 탄환과 산탄총을 12%·50%·100% 충전량으로 각각 검사했습니다. 관측된 수평 거리 비율은 약 1.99~2.01배였고 도화선 시간은 동일했습니다. 유도탄은 목표의 수평 거리도 같은 비율로 맞춰 비교했습니다. 지형·물·바람·상대 캐릭터 충돌에 따라 실제 전장에서 도달하는 거리는 달라집니다.

실제 키보드로 Space를 1.75초 눌러 게이지 100%를 확인한 뒤 놓았을 때 확대된 최대 추진력으로 발사되는 것을 검사했습니다. CPU는 약 2,500픽셀 떨어진 적에 유효한 조준을 선택했고 예측한 충돌 좌표와 실제 고정 간격 탄환 계산의 차이는 0이었습니다. 해당 검사는 지형과 캐릭터 위치를 통제한 재현입니다.

1280×900 데스크톱과 320×568, 390×844, 844×390 모바일 화면에서 핵심 항목 표시, 추가 설정의 기본 접힘, 터치로 열기·닫기, 시작 버튼의 초기 노출과 전투 시작·일시정지를 확인하고 캡처했습니다. 추가 설정 변경 후 재접속해 값을 복원하고, 접힌 상태에서도 다음 전투에 적용되는 것을 확인했습니다.

## 전체 검사

로컬 검사 512개 통과: 이번 거리·시작 화면 44, 기존 전투·브라우저 170, 저장 16, CPU 20, 배포 묶음 13, 이미지 9, 테마 41, 표시·오프라인 14, 배경음악 15, 음량 19, 시작 화면 음량 14, 오류 회귀 16, 효과음 118, 오프라인 효과음 3.

기존 자동 검사는 추가 설정을 펼친 뒤 세부 옵션을 검사하도록 갱신했습니다. 새 화면의 기본 접힘·핵심 항목만 표시되는 상태는 별도의 range-setup.json 검사로 확인합니다. 테마 검사에서 재접속 후 접힌 세부 항목을 조작하려던 검사 절차도 수정하고 다시 통과했습니다. 게임 실행 오류를 설정 화면 검사 오류와 구분했습니다.

모든 무기·턴 전환·피해·사망·카메라 대기·CPU 행동과 음량 저장을 회귀 검사했습니다. 배포 ZIP 추출본의 저장소 하위 경로, 로컬 분리본, 네트워크를 끈 단일 HTML도 실행했습니다. JavaScript 오류와 검사 대상 리소스 누락은 없습니다.
