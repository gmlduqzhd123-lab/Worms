# 모바일 화면 맞춤·종료·시작 카메라 — 2026-10-25

## 수정 내용

1. 기존 캔버스가 innerWidth/innerHeight를 사용해 브라우저 표시 영역과 달라질 수 있었습니다. 이제 배율 1에서 visualViewport의 너비·높이·오프셋을 캔버스와 UI에 동일하게 적용합니다. 주소창 변화·회전·전체 화면 변경에 다시 계산하고, 실제 캔버스 위치를 빼서 터치 좌표를 월드 좌표로 변환합니다. visualViewport가 없는 환경은 기존 크기로 동작합니다.
2. 모바일 보조 조작이 전장을 많이 가렸습니다. 일시정지·전체 화면·게임 종료는 바로 표시하고, 가이드·기록·음악·효과음·음량·카메라 버튼은 설정 메뉴에 묶었습니다. 노치·홈 표시줄 안전 영역과 높이 320px 이하 화면의 작은 버튼·한 줄 무기 이름을 적용했습니다. 무기 목록은 의도적으로 가로 스크롤합니다.
3. 게임 종료 버튼과 확인창을 추가했습니다. 확인창에서 전투·소개를 정지하고 취소하면 이전 일시정지 상태를 복원합니다. 종료하면 시작 화면으로 돌아가고 포탄·예약 공격·CPU 상태·입력을 비웁니다. 미완료 대전을 승패 기록으로 저장하지 않으며 이전 설정·완료 기록은 유지합니다. 게임 종료는 브라우저 탭을 닫는 기능이 아닙니다.
4. 시작 직후 양 팀 전체 위치를 2초 보여주고 기존 캐릭터별 2초 소개를 이어갑니다. 첫 플레이 차례에도 아군과 적 NPC 전체가 보이도록 위치 범위에 맞춰 카메라를 유지합니다. 작은 전체 보기에서 캐릭터의 최소 표시 크기를 확보하고 낮은 화면에서는 머리 위 체력 표시를 짧게 배치합니다. 발사하면 포탄 추적을 재개하고, 사용자가 확대·드래그·봇 추적을 선택해도 전체 보기 유지가 해제됩니다. 다음 턴은 기존 캐릭터 추적 방식입니다.
