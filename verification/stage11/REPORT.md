# 11단계 발사 화면 유지·머리 위 체력 연출

발사체가 사라지면 즉시 현재 캐릭터를 따라가던 카메라를 수정했습니다. 마지막 발사체·폭발·산탄총 충돌 위치를 저장하고 마지막 충돌 뒤 최소 3초 유지합니다. 여러 발과 분열탄은 마지막 발사체까지 추적합니다. 체력 감소 연출이 더 오래 걸리면 모두 끝날 때까지 자동 카메라 복귀·턴 교대·승리 전환을 기다립니다. 기존 수동 카메라 조작은 유지합니다.

각 캐릭터의 이름과 HP를 머리 위 두 줄로 분리하고 작은 체력 막대를 추가했습니다. 피해를 받으면 숫자가 현재 표시값에서 새 체력까지 내려가고, 붉은 막대와 노란 잔상·피해 숫자를 표시합니다. 사망해도 HP가 0까지 내려간 뒤 잠시 0을 보여줍니다. 연속 피해는 현재 표시값에서 이어지고, 물에 빠진 사망도 0까지 표시합니다. 회복 아이템은 이전 피해 연출을 취소하고 회복한 체력을 표시합니다.

실제 체력·사망·충돌 판정은 즉시 적용합니다. 화면 표시만 0.9~4초에 걸쳐 감소하며 마지막 값은 0.35초 유지합니다. 일시정지하면 카메라 유지 시간과 체력 연출 시계가 함께 멈춥니다. 새 게임에서는 이전 연출을 초기화합니다.

원본 및 이전 버전은 보존했습니다. versions/stage10/의 파일 82개는 stage10-preservation.json의 SHA256과 일치합니다. 앱 설치·QR·공유 기능, 10개 테마, 이미지 30장, GitHub Pages·단일 HTML 실행을 유지했습니다.

개별 검사 결과는 results.json, reference.json, release.json, themes.json, features.json, artwork.json, tactics.json에 기록합니다. 새 전투 검사는 3초 유지와 복귀, 3초를 넘는 체력 연출, 연속 피해, 일시정지, 조기 턴 넘김·승리 차단, 재시작, 머리 위 HP 위치, 사망 후 0 표시, 회복과 물 사망을 확인합니다. 모바일은 브라우저 에뮬레이션이며 실제 기기 검수는 포함하지 않습니다. 공개 검수는 verification/live-stage11/에 별도 기록합니다.
