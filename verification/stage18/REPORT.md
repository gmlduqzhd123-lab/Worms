# 18단계 전투 오류 점검과 효과음 개선

이전 17단계 파일을 실제 Edge 브라우저에서 실행해 문제를 재현한 뒤 수정했습니다. 변경본 로컬 검사 468개가 통과했습니다. 공개 배포 결과는 ../live-stage18/REPORT.md에 별도로 기록합니다.

## 발견한 문제와 수정

- 지뢰·다이너마이트 설치 즉시 공격 잠금으로 이동할 수 없어, 평지 재현에서 설치자의 HP가 각각 100→63, 100→38로 줄었습니다. 설치 직후 지뢰 2.5초·다이너마이트 3초 동안 이동과 점프를 허용하고 추가 공격은 막았습니다. 지뢰는 1.8초 감지 유예를 적용합니다. 후퇴 시간과 도화선은 일시정지에 따라 함께 멈춥니다.
- 지형 깊은 곳을 텔레포트 목표로 누르면 몸통이 지형에 묻혔습니다. 선택한 열에서 몸통이 들어갈 빈 공간과 발판을 찾아 이동하고, 월드 밖·물속·다른 캐릭터와 겹치는 위치는 거절합니다. 실패한 이동은 탄약을 쓰거나 효과음을 내지 않습니다.
- 시작 화면 팀 이름의 공백 입력과 방향키를 게임 키가 가로챘습니다. 입력 필드의 기본 편집을 유지하며, 키보드로 초점을 준 버튼은 Space/Enter로 작동하고 포인터로 버튼을 선택한 뒤에는 게임 키가 정상 작동합니다.
- 모바일 핀치에서 한 손가락을 뗀 뒤 10px 이동하면 카메라가 191.67월드px 급이동했습니다. 남은 손가락의 위치를 새 드래그 기준으로 설정해 확대율 1.2에서 8.33월드px 이동하도록 수정했습니다. 목표 지정 무기는 이 동작으로 발사되지 않습니다.
- 게임 시작의 턴 효과음 중복 호출을 제거했습니다. 일시정지·재시작 뒤 예약 효과음이나 엔진 소리가 남지 않도록 소스를 정리합니다.

재현 자료는 fixes-before.json, 수정 후 16개 경계 검사 자료는 fixes.json입니다. 고정 지형·게임 시계를 사용한 재현과 실제 키보드·터치 입력을 함께 사용했습니다.

## 효과음

단발 44종과 제트팩·드릴 지속음 2종을 Web Audio로 합성했습니다. 로켓·유도탄·박격포 발사, 투척과 금속성 튕김, 무기별 폭발·자탄, 산탄총과 펌프 장전, 발걸음·점프·착지·피격, 설치·도화선·지뢰 경보, 로프·거더·텔레포트, 획득·턴·승리·서든데스를 구분했습니다. 성스러운 폭탄의 화음은 가능한 경우 폭발 전에 시작합니다. CPU 탄도 예측에는 효과음이 발생하지 않도록 실제 탄환 처리에서만 충돌음을 냅니다.

선택한 배경음악·효과음 음량, 0%/OFF, 시작 화면과 게임 화면의 연동·저장을 유지합니다. 주요 폭발·산탄총만 음악을 잠시 줄이고 복원합니다. 효과음 압축기·공통 출력 제한기, 18개 이벤트/128개 노드 상한과 효과별 최소 간격을 적용했습니다. 종료된 오디오 노드를 해제하고 오디오 전용 난수를 사용합니다. 닫힌 AudioContext를 복구하는 경우도 검사했습니다. 상세 구성은 ../../assets/audio/EFFECTS.md입니다.

## 검수 결과

Edge 155.0.4283.45에서 총 468개 통과: 전투·브라우저 170, 저장 16, CPU 20, 배포 묶음 13, 이미지 9, 테마 41, 표시·오프라인 14, 배경음악 15, 음량 19, 시작 화면 음량 14, 오류 회귀 16, 효과음 118, 오프라인 효과음 3.

실제 UI로 시작·발사·턴 전환·CPU 복귀·정지·설정 저장을 확인하고, 통제된 상태로 모든 무기, 낙하·피해·사망·다중 피해 카메라와 턴 대기를 검사했습니다. 데스크톱 및 320×568, 390×844, 844×390 화면에서 배치·터치·핀치·취소를 검사했습니다. 배포 ZIP을 추출한 파일, 저장소 하위 경로, 로컬 분리본과 네트워크를 끈 단일 HTML을 실행했습니다. JavaScript 오류와 검사 대상 리소스 누락은 없었습니다.

44종 효과음 각각의 유한한 출력·감쇠·피크, 100% 음량에서 겹친 출력, 실제 AudioContext 신호·음소거·음악 복원·지속음 종료를 검사했습니다. 단일 HTML에서는 음악을 끈 후 UI로 산탄총을 발사하여 출력 신호를 측정하고 효과음 OFF에서 두 번째 발사가 무음임을 확인했습니다. 네트워크 요청은 없었습니다.

## 보존과 실행 파일

17단계의 98개 파일은 versions/stage17에 보존했으며 stage17-preservation.json의 SHA-256과 일치합니다. 기존 original/·이전 버전·제공 MP3는 수정하지 않았습니다. 실행용 61개 파일의 명세는 release/manifest.json, ZIP은 release/wormfront-stage18-pages.zip입니다. 단일 파일은 dist/wormfront-stage18-offline.html(59,836,651 bytes)입니다.

## 확인 범위의 한계

- [제공된 원작 영상](https://www.youtube.com/watch?v=q-90JSwX-sY&t=324s)의 브라우저 재생·전투 장면을 확인했습니다. 효과음은 독자 합성했으며 원작 음원은 포함하지 않았습니다. 원작과의 직접 청감 A/B 비교를 수행하지 못했으므로 동일한 음색이나 주관적 유사도를 검증했다고 주장하지 않습니다.
- 모바일은 브라우저 에뮬레이션입니다. 실제 휴대전화·iOS Safari·실제 스피커/헤드폰에서의 청감과 장시간 발열·배터리는 검수하지 않았습니다.
- 분리본 index.html을 file URL로 직접 열면 브라우저 정책에 따라 MP3 fetch가 제한될 수 있습니다. 음악을 포함한 로컬 실행은 로컬 HTTP 서버, 완전한 오프라인 실행은 모든 리소스를 포함한 단일 HTML을 사용합니다.
- 검사한 시나리오에서 오류를 찾고 수정한 결과이며, 모든 환경의 무결함을 보증하는 것은 아닙니다.
