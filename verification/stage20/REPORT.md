# 20단계 모바일 가로 화면과 웜 소개

## 적용 내용

모바일 세로 화면에서는 ‘원활한 플레이를 위해 스마트폰을 가로로 돌려주세요.’ 안내가 화면을 덮고 게임 조작을 막습니다. 소개와 전투의 진행을 멈추며 가로로 돌아오면 회전 때문에 멈춘 경우에만 자동으로 이어집니다. 사용자가 직접 정지했거나 가이드·기록 창을 열어 멈춘 상태는 회전 후에도 유지합니다. 가이드가 열린 상태의 세로 전환에서는 가이드를 잠시 가려 회전 안내를 보여주고, 가로로 돌아오면 가이드를 복원합니다. 누르고 있던 이동·충전 입력은 회전 시 해제합니다.

viewport-fit=cover, 동적 뷰포트 높이, 노치·홈 표시 영역의 safe-area를 반영했습니다. 캔버스 크기와 화면 크기를 함께 갱신하며, 넓은 가로 스마트폰에서도 터치 조작부가 나타납니다. 게임 시작 버튼의 사용자 동작 안에서 전체 화면을 요청하고 게임 중 전체 화면 버튼으로 재시도·해제할 수 있습니다. API 미지원이나 거절 시에도 현재 브라우저 뷰포트에 맞춰 게임을 실행합니다.

전투 전에는 내캐릭1~4, NPC1~4를 순서대로 한 마리당 2초씩 소개합니다. 기본 8마리는 총 16초이며 팀 인원 설정에 따라 전체 순회 길이가 바뀝니다. 각 웜의 위치·머리 위 이름/체력과 소개 패널을 표시하고 주변 전장을 보여줍니다. ‘소개 건너뛰기’ 버튼을 제공합니다. 소개 중에는 물리·지뢰·공격·CPU 작업·턴 시간과 대전 기록 시간을 진행하지 않습니다. 소개가 끝나거나 건너뛰면 내캐릭1로 돌아와 새 턴 시간을 시작합니다. 일시정지는 소개 시간도 멈추며 재시작은 첫 웜부터 다시 소개합니다.

## 발견한 문제와 수정

- 지형 생성 전에 기록된 프레임 시각이 첫 소개에 포함되어 첫 웜 표시가 약 1.7~1.85초로 짧아지는 문제를 발견했습니다. 소개 시작·재개 시각을 초기화하고 프레임 시각이 뒤로 돌아가지 않도록 수정한 뒤, 실제 순회 간격을 다시 측정했습니다.
- 가로 화면의 노치 여백을 추가했을 때 기존 중앙 정렬 transform이 남아 상단 HUD가 화면 밖으로 밀리는 문제를 수정했습니다. 가로 모바일에서는 좌우 안전 여백을 기준으로 폭과 위치를 계산합니다.
- 소개·회전 동작을 별도로 검증하고, 기존 전투 자동 검사는 소개를 건너뛴 뒤 전투 기능을 검사하도록 분리했습니다. 이 동작 분리는 검사 도구에만 있으며 배포 코드에는 검사 전용 스위치를 넣지 않았습니다.

## 검수

로컬 총 538개 검사 통과: 이번 모바일·소개 26, 거리·시작 설정 44, 기존 전투·브라우저 170, 저장 16, CPU 20, 배포 묶음 13, 이미지 9, 테마 41, 표시·오프라인 14, 배경음악 15, 음량 19, 시작 화면 음량 14, 오류 회귀 16, 효과음 118, 오프라인 효과음 3.

수정 없는 새 기능 경로를 실제 Edge에서 검수했습니다. 기본 8마리를 실제 시간으로 순회해 순서·표시 간격·HP·위치를 기록했고, 팀 인원 2·6명의 2초 경계도 제어된 프레임으로 검사했습니다. 소개 중 키보드 이동·발사·턴 넘김·줌 차단, 건너뛰기, 정지, 재시작, 첫 턴 시간 복원을 확인했습니다.

390×844 세로, 844×390·568×320·932×430 가로와 데스크톱을 검사했습니다. 회전 전용 자동 정지·복귀, 수동 정지 유지, 조작 입력 해제, 가이드 표시 복원, 캔버스 리사이즈, 좌44/우34/상12/하20픽셀의 가상 안전 여백을 검증했습니다. 신뢰된 터치 시작으로 Edge의 실제 전체 화면 진입·해제·재진입을 확인했고, 전체 화면 거절·미지원 경로도 검수했습니다.

배포 ZIP 추출본과 로컬 분리본·단일 HTML을 검사했습니다. 네트워크를 끈 단일 HTML에서도 세로 안내 → 가로 전환 → 소개 → 건너뛰기 → 첫 턴이 동작하고 외부 네트워크 요청이 없음을 확인했습니다. JavaScript 오류와 검사 대상 리소스 누락은 없습니다.

## 보존·배포와 한계

19단계 105개 파일은 versions/stage19에 보존했으며 stage19-preservation.json의 SHA-256과 일치합니다. original/와 기존 보관본, 제공 이미지·MP3를 유지합니다. 배포 ZIP은 release/wormfront-stage20-pages.zip(실행 파일 61개), 단일 HTML은 dist/wormfront-stage20-offline.html입니다. 공개 배포 결과는 ../live-stage20/REPORT.md에 기록합니다.

모바일 검수는 실제 Edge의 터치·화면 에뮬레이션입니다. 실제 스마트폰·iOS Safari의 주소창·노치·OS 회전 동작은 검수하지 않았습니다. 브라우저가 전체 화면을 허용하지 않는 경우에는 브라우저의 콘텐츠 영역을 채우는 방식으로 실행하며 주소창 제거를 보장하지 않습니다.
