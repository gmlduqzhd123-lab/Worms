# 17단계 시작 화면 음량 조절

시작 화면에 배경음악·효과음 슬라이더와 퍼센트 표시를 추가했습니다. 게임 중 설정과 같은 musicVolume·sfxVolume 상태를 사용하며, 한쪽을 조절하면 다른 쪽의 슬라이더와 표시도 갱신됩니다. 기존 저장 형식을 유지하여 새로 접속한 시작 화면·전투 시작·전투 종료 후 시작 화면·재시작에 같은 값을 복원합니다. 0% 무음과 ON/OFF 상태도 유지합니다.

시작 화면의 슬라이더 키보드 입력이 게임 조작으로 전달되지 않도록 처리했습니다. 시작 화면을 덮던 게임 중 음량 버튼의 표시 순서도 수정했습니다. 기존 배경음악과 자동 음량 감소·복원은 유지합니다.

로컬 검사 331개 통과: 전투·브라우저 170, 저장 16, CPU 20, 배포본 13, 이미지 9, 테마 41, 표시·오프라인 14, 배경음악 15, 음량 19, 시작 화면 음량 14. JavaScript 오류·누락 리소스는 없습니다. 새 검사에는 양방향 슬라이더 동기화, 실제 전투 음량 적용, 전투 종료 화면과 재시작, 재접속 및 0% 저장, 키보드·모바일 터치, 단일 HTML의 시작 화면 음량을 포함합니다. 전투 종료 화면은 제어된 승리 상태를 만들어 검수했습니다.

1280×900, 320×568, 390×844, 844×390에서 시작 화면을 캡처하고 작은 화면의 실제 이미지도 확인했습니다. 모바일 검수는 브라우저 에뮬레이션이며 실제 휴대전화 검수는 수행하지 않았습니다.

원본과 제공 MP3는 수정하지 않았습니다. 이전 실행 파일 96개를 versions/stage16에 보존하고 stage16-preservation.json의 SHA-256과 일치함을 확인했습니다. 배포 ZIP은 61개 실행 파일을 포함하며 해시와 추출본 실행을 검사했습니다. 공개 배포 검수는 ../live-stage17에 기록합니다.
