# 전투 난이도·혼합 배치·연출·전체 탄도 — 2026-10-27

## 적용한 여섯 항목

1. **난이도:** 기본 보통 CPU의 조준 오차를 ±4°에서 ±6°로, 이동 탐색 범위를 130에서 110으로 조정했습니다. 탐색 간격도 조금 넓히고 발사 준비 시간을 350ms에서 650ms로 늘렸습니다. 쉬움·보통은 바람포/통통캡슐을 사용하며 자동 유도 무기는 어려움에서 사용합니다. 어려움 설정과 플레이어의 기존 난이도 선택은 유지합니다. 플레이어 체력·무기 피해 계수는 바꾸지 않았습니다.
2. **혼합 배치:** 전장 폭의 7~93% 구간에서 안전한 지점을 찾고 팀 소속을 무작위로 섞습니다. 2명 이상인 팀은 단순 좌우 분할이 되지 않도록 최소 두 번 팀이 교차합니다. 모든 캐릭터의 최소 수평 간격은 게임 좌표 150이며 물·막힌 공간을 피합니다. 지뢰는 기존 거리 110 이상을 유지해 안전한 위치가 확보되는 수만 배치합니다. 차례 시작 시 가장 가까운 적 방향을 바라봅니다. 이름·팀 색·외형 선택·위치 소개·초기 전체 보기는 유지합니다.
3. **포탄·착탄:** 포탄의 화면상 크기와 잔상, 폭발 섬광·확산 고리·파편·연기를 확대했습니다. 포탄 잔상은 28개 지점, 파티클은 900개로 제한했습니다. 화면 흔들림은 최대 6px로 줄여 큰 효과에서도 상황을 읽기 쉽게 했습니다. 실제 충돌 반경·탄속·중력·피해·넉백 계수는 그대로입니다.
4. **피격:** 짧은 몸 흔들림·눌림·반동 자세·흰 섬광·충격선을 추가하고 피해 숫자를 화면 픽셀 기준으로 키웠습니다. 숫자는 피해 캐릭터를 따라가며 화면 안에 머뭅니다. 낮은 가로 화면에서는 피해 숫자·카메라 여백을 조정하고, 멀리 보이는 피해 캐릭터도 최소 크기를 확보했습니다. 렌더링이 실제 캐릭터 위치·속도·체력·충돌 원을 바꾸지 않는지 확인했습니다.
5. **사망:** 체력 표시 감소가 끝난 뒤 사망 동작을 하고, 최종 위치에서 작은 섬광·고리·연기·파편을 보여줍니다. 폭발 후 효과가 끝날 때까지 사망 표시와 턴 대기를 유지합니다. 이 효과는 별도 시각 함수이며 주변 체력 감소·지형 파괴·지뢰 연쇄 폭발을 일으키지 않습니다.
6. **탄도:** 실제 발사/CPU가 사용하는 `advanceBallistic` 고정 시간 계산으로 점선을 충돌·반사·신관 종료까지 그립니다. 안정된 결과는 재사용하며 힘·바람·각도·좌우 방향·캐릭터 위치·지형·발판·목표 변화 시 갱신합니다. 착탄·피격·폭발·수면·맵 밖 등을 구분하고 현재 힘을 표시합니다. 미충전/짧은 탭은 실제 최소 힘 12%이며 숫자·게이지·점선을 일치시켰습니다. ‘탄도 전체’로 경로를 맞추고 발사하면 포탄 추적으로 복귀합니다. 드래그/확대/봇 추적은 자동 맞춤을 해제합니다.
