# 16단계 독립 음량 조절과 저장

게임 오른쪽 위 음량 버튼을 열면 배경음악과 효과음의 슬라이더가 표시됩니다. 각각 0~100%로 조절하며 기본값은 이전과 같은 음악 18%, 효과음 72%입니다. 퍼센트 표시와 실제 음악·효과음 버스를 함께 갱신합니다. 0%는 무음이고 ON/OFF 상태와 별도로 저장합니다. 효과음의 음량이 0%일 때는 음악 음량을 낮추지 않습니다.

기존 wormfront.settings.v1에 musicVolume·sfxVolume을 추가하여 다음 접속과 새 게임에도 복원합니다. 과거 저장에는 기본값을 적용하고 잘못된 형식은 무시하며 범위를 벗어난 숫자는 안전하게 제한합니다. 슬라이더에서 누르는 방향키·스페이스 등은 게임 이동이나 발사로 전달하지 않습니다. 효과음 후 음악 음량 복원도 사용자가 선택한 값으로 수행합니다.

로컬 검사 317개 통과: 전투·브라우저 170, 저장 16, CPU 20, 배포본 13, 이미지 9, 테마 41, 표시·오프라인 14, 배경음악 15, 음량 19. JavaScript 오류·누락 리소스는 없습니다. 음량 검사에는 실제 키보드·모바일 터치 입력, 두 버스의 음량 변화, 효과음 후 복원, OFF 상태 유지, 다시 접속한 뒤 복원, 0% 저장, 잘못된 저장 값 처리, 단일 HTML의 슬라이더·저장을 포함합니다.

320×568, 390×844, 844×390 화면에서 음량 패널을 검사하고 스크린샷을 확인했습니다. 모바일은 브라우저 에뮬레이션이며 실제 휴대전화 검수는 수행하지 않았습니다. 오디오 게인 검사에서는 효과음 버스의 렌더링을 유지하기 위해 값 0의 무음 소스를 연결합니다. 실제 효과음 생성 로직을 대체하지 않습니다.

제공 MP3와 원본은 변경하지 않았습니다. 이전 실행 파일 94개를 versions/stage15에 보존하고 stage15-preservation.json의 SHA-256과 일치함을 확인했습니다. ZIP 61개 실행 파일의 해시 및 추출본 실행을 검사했습니다. 공개 배포 검수는 ../live-stage16에 별도로 기록합니다.
