# 실제 플레이 영상 관찰 및 반영

참고: [옥냥이의 웜즈 아마겟돈 플레이](https://www.youtube.com/watch?v=q-90JSwX-sY&t=324s). 2026-10-11 브라우저에서 직접 재생해 관찰했습니다. 약 38분 41초 영상 전체를 연속 시청한 것은 아니며 아래 대표 구간을 확인했습니다. 자동 자막은 보조 자료로만 사용했습니다.

## 이번 적용

턴 정보를 이동·조준, 발사력 충전, 공격 진행, 폭발·낙하 결과 확인, 후퇴, 교대, 일시정지로 나눠 표시합니다. 화면의 남은 시간은 조작 가능한 턴 시간과 후퇴 시간을 구분합니다. 폭발 해결 중에는 중단된 턴 시간 대신 진행 기호를 표시합니다.

HUD를 중앙의 작은 패널로 줄이고 팀 체력 막대 높이와 여백을 줄였습니다. 작은 모바일 화면에서도 단계 안내를 표시합니다. 활성 팀 패널 테두리와 캐릭터 위 화살표가 현재 조작 대상을 알려 줍니다. 캐릭터 이름과 HP는 팀 색으로 표시합니다.

피해 숫자는 반올림 후 실제 줄어든 HP입니다. 체력 17인 캐릭터에 100 피해를 주면 17로 표시합니다. 잠시 떠오른 뒤 사라지고 일시정지하면 멈춥니다. 수류탄·바나나·성스러운 수류탄·클러스터·다이너마이트에 남은 기폭 초를 표시합니다. 기존 기폭 시간, 탄도, CPU 시뮬레이션은 유지했습니다.

## 해석 및 후속 차이

가벼운 분위기는 밝은 전장, 작은 캐릭터, 큰 폭발과 넉백의 대비에서도 나온다는 해석을 적용했습니다. 원작 이미지·음원은 영상에서 추출하지 않았습니다. 이번 변경은 전투 흐름과 표시의 첫 반영입니다.

영상처럼 여러 팀이 참여하는 전투, 별도 모양의 연결되지 않은 섬·구조물 지형, 동작별 캐릭터 애니메이션, 원작의 모든 무기·로프 감각까지 구현한 것은 아닙니다. 영상 소리를 직접 청취해 음악·효과음의 유사성을 검증하지 않았으며 기존 오디오를 유지했습니다. 모든 테마는 현재 같은 물리 규칙을 사용합니다.
