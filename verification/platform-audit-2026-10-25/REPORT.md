# PC·모바일·태블릿 호환성 재검수 — 2026-10-25

## 발견 문제와 수정

1. **터치 기기 인식 누락:** 기존 코드는 터치 포인트 수·주 포인터·1024px 조건에 의존했습니다. 데스크톱형 UA를 쓰면서 터치 포인트를 0으로 보고하는 WebKit 조건과, 주 포인터가 마우스인 터치 혼합 환경에서 조작부가 누락되는 것을 재현했습니다. `ontouchstart` 및 `any-pointer:coarse`를 함께 확인하고 포인터 조건 변경에도 갱신합니다. 터치 레이아웃에서 턴 넘김을 표시하고 PC 힌트·미니맵이 버튼을 가리지 않도록 했습니다. 회전 문구에도 태블릿을 명시했습니다.
2. **WebKit 선택 상자 대비:** 네이티브 선택 상자의 밝은 배경과 밝은 글자가 겹쳤습니다. 시작 설정·각도 선택에 어두운 배경과 직접 그린 선택 화살표를 적용하고 브라우저 간 글꼴도 상속합니다. 선택 상자 화면 픽셀과 실제 조작으로 확인했습니다.
3. **태블릿 상단 겹침:** 넓은 터치 화면에서 추가 팀 정보가 세션 버튼 위치까지 내려왔습니다. 터치 레이아웃의 추가 메타 정보를 접어 버튼과 분리했습니다. 캐릭터 머리 위 체력 표시는 유지합니다.
4. **첫 접속 직후 오프라인 이미지 누락:** 기존 서비스 워커는 이미지 파일을 선저장하지 않아 새 방문의 이미지 캐시가 0개였고, 오프라인 재접속 시 캐릭터·도구·배경 21개가 실패했습니다. 이제 30개 PNG를 처음에 모두 저장해 아직 고르지 않은 테마도 오프라인에서 열립니다. 캐시 쓰기 완료를 기다리고 저장 실패가 정상 네트워크 응답을 막지 않도록 했으며 정적 파일 캐시의 Vary 차이도 처리했습니다.

## 검사 도구의 한계와 보정

WebKit은 닫힌 details 내부의 요소를 자동화의 isVisible에서 보이는 것으로 반환할 수 있어 메뉴의 open 속성을 확인하도록 검사 코드를 보정했습니다. 또한 WebKit의 offline 플래그는 간단한 로컬 HTML까지 file:// 탐색 오류를 내는 것을 별도 최소 파일로 재현했습니다. WebKit 단일 파일은 HTTP 요청을 모두 차단하는 경로로 검수했고 요청 0개를 확인했습니다. Edge·Chrome 단일 파일은 브라우저 offline 플래그를 사용했습니다. 이 도구 차이를 앱 버그로 기록하지 않았습니다.

병렬 검사 중 큰 WebKit 화면의 1.5초 입력 안정화 제한에 걸린 항목은 제한을 5초로 조정하고 단독 재검수했습니다. 최종 전체 검사는 통과했습니다. 초기 진단 결과 `before/results.json`에는 이러한 검사 하네스 판정도 포함되므로 최종 통과 여부는 `local/results.json`을 기준으로 합니다.

이번 v27의 Android·iPad·Windows 태블릿 실물, iOS 앱 설치·공유 카드, Firefox는 직접 확인하지 않았습니다. 이전 v25의 사용자 Android 확인을 이번 버전의 실기기 통과로 옮겨 적지 않았습니다.
