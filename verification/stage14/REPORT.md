# 14단계 안전한 시작·기본 캐릭터 이름·맵 만들기 제거

시작 캐릭터를 지형에 겹치지 않고 발밑에 지지점이 있는 안전한 위치에 배치합니다. 수면과 충분히 떨어진 지점을 고르고, 캐릭터를 먼저 배치한 뒤 모든 시작 지점에서 110픽셀 이상 떨어진 곳에 중립 지뢰를 생성합니다. 낙하 피해·지뢰의 일반 전투 동작은 유지합니다.

기본 4명 이름은 내캐릭1~4, 상대 팀은 NPC1~4입니다. 캐릭터 수 설정을 바꾸면 같은 규칙으로 번호를 이어갑니다. 새 맵 미리 만들기 버튼과 이벤트 처리를 제거했습니다. 전투 시작에 필요한 지형 생성, 기존 테마·맵 크기 선택은 유지합니다.

PC·모바일 세 가지 화면 크기에서 고정 난수 36개 조건을 검수했습니다. 캐릭터 2·4·6명, 맵 크기 2.5·4·6배, 10개 테마, 초기 지뢰 18개를 조합하여 시작 위치가 안전하고 5초 동안 전원이 HP 100·생존 상태를 유지하며 피해·사망·자동 공격이 없음을 확인했습니다. 실제 기기 대신 브라우저 에뮬레이션을 사용했습니다.

원본과 이전 버전을 보존했습니다. versions/stage13의 실행 파일 82개를 stage13-preservation.json의 SHA-256으로 검수합니다. 개별 로컬 검사 결과는 이 폴더의 JSON, 공개 검수는 ../live-stage14에 기록합니다.

로컬 검사 총 283개 통과: 전투·브라우저 170, 저장 16, CPU 20, 배포본 13, 이미지 9, 테마 41, 표시·오프라인 14. JS 오류·누락 리소스 0개. ZIP 60개 실행 파일 해시와 단일 HTML 오프라인 실행을 확인했습니다. 단일 HTML은 57,559,009 bytes입니다.
