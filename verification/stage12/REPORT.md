# 12단계 피해 캐릭터 추적·동시 피해 자동 줌

피해를 받은 캐릭터의 실제 위치를 카메라가 추적합니다. 밀려남과 낙하가 끝나지 않으면 체력 감소 연출과 마지막 충돌 3초 유지가 끝났어도 자동 복귀·턴 전환을 기다립니다. 여러 캐릭터가 피해를 받으면 그룹의 위치 범위를 매 프레임 다시 계산하여 함께 화면에 담습니다. 빠른 밀려남에는 즉시 축소하고, 다시 확대하거나 일반 전투 화면으로 복귀할 때는 부드럽게 전환합니다.

HP 숫자·이름·체력 막대는 자동 축소 중에도 화면 글자 크기를 유지합니다. 수동 드래그·줌·전체 맵은 자동 추적보다 우선하며, 새 전투·새 턴에서 추적 상태를 초기화합니다. 종료된 전투의 지연 화면 표시가 새 전투를 덮는 문제도 방지했습니다.

원본 HTML·이미지 원본·이전 버전은 보존했습니다. 이전 실행본 82개 파일은 versions/stage11에 복사하고 stage11-preservation.json의 SHA-256으로 확인합니다. 배포물에는 실행 파일만 포함합니다. GitHub Pages의 설치·QR·서비스 워커 기능과 로컬·단일 HTML 오프라인 실행을 유지합니다.

검수 결과는 같은 폴더의 results.json, features.json, tactics.json, release.json, artwork.json, themes.json, reference.json에 기록합니다. 새 검사는 실제 낙하 물리 중 HP 연출 종료 이후의 추적, 동시 피해 범위와 추가 밀려남에 따른 재계산, 확대율 복원, 읽을 수 있는 HP 크기, 수동 조작 및 320×568·390×844·844×390 표시 범위를 확인합니다.

모바일 검수는 Edge의 터치·화면 크기 에뮬레이션입니다. 공개 사이트 검수는 verification/live-stage12에 별도로 기록하며, 강제로 피해를 입력하는 재현 검사와 실제 UI에서 무기를 발사하는 검사를 구분합니다.

로컬 검수: 전투·브라우저 123, 저장 16, CPU 20, 배포본 13, 이미지 9, 테마 41, 표시·오프라인 14로 총 236개 검사 통과. 브라우저 JS 오류·누락 리소스 0개. ZIP의 60개 실행 파일 해시 및 네트워크 없이 실행되는 단일 HTML을 확인했습니다. 단일 HTML 크기는 57,557,390 bytes입니다.
