# 18단계 효과음

44개 단발 효과와 제트팩·드릴 지속음을 Web Audio로 합성합니다. 원작의 만화적인 전투를 목표로 소음을 여과한 충격음, 음높이 변화, 짧은 기계음과 잔향을 조합했습니다. 원작 음원 파일은 포함하지 않습니다.

| 동작 | 구성 |
| --- | --- |
| 로켓 / 유도탄 / 박격포 | 압축공기·추진음 / 전자 준비음과 추진음 / 낮은 발사 충격과 휘파람 |
| 수류탄·바나나·클러스터 | 던지는 소리, 지형에 튕길 때 금속성 충돌, 도화선 |
| 폭발 | 무기별 저역·파편·감쇠 시간 구분, 작은 자탄은 짧고 낮은 음량 |
| 산탄총 | 짧은 총성, 저역 충격, 뒤따르는 펌프 장전음 |
| 지뢰 / 다이너마이트 | 설치 충격, 지뢰 감지 경고 / 도화선과 긴 폭발 꼬리 |
| 성스러운 폭탄 | 폭발 직전 화음, 큰 폭발과 높은 잔향 |
| 배트 / 펀치 | 만화적인 타격 / 공기를 가르는 소리와 무거운 충격 |
| 걷기·점프·착지·피격 | 작은 발소리, 상승하는 점프음, 낮은 착지 충격, 짧은 피격음 |
| 로프 / 거더 / 텔레포트 | 발사·걸림·해제 / 금속 조립 / 상승하는 전자음과 도착음 |
| 제트팩 / 드릴 | 시동 후 실제 사용 상태에 따라 이어지는 추진음 / 모터음 |
| 아이템·턴·승리·서든데스 | 짧은 알림, 차례 구분, 종료 화음, 경보 |

배경음악 기본 18%, 효과음 기본 72%와 시작·게임 화면의 저장 설정은 유지합니다. 큰 폭발과 산탄총만 음악을 선택 음량의 45%로 잠시 줄입니다. 발소리·메뉴 클릭은 음악 음량에 영향을 주지 않습니다. 효과음 압축기와 공통 출력 제한기로 동시 폭발의 피크를 제한하고, 최대 18개 이벤트·128개 노드와 효과별 최소 간격을 적용합니다.

일시정지·탭 숨김·효과음 OFF/0%·새 전투에서는 재생 중이거나 예약된 효과음을 중단하고 연결을 해제합니다. 사용이 끝난 소리도 정리합니다. 효과음 난수는 지형·CPU의 난수와 분리합니다.

참고: [사용자가 제공한 원작 플레이 영상](https://www.youtube.com/watch?v=q-90JSwX-sY&t=324s). 브라우저 재생과 전투 화면을 확인했습니다. 직접 청감 A/B 비교는 수행하지 못했으며, 원작과 동일한 음색을 검증한 것은 아닙니다. 수치 검수는 scripts/verify-sfx.cjs와 verification/stage18/sfx.json에 기록합니다.
